⚠️ IFRS 포괄손익 입력 유의사항

• 기타포괄손익(OCI)은 당기순이익에 포함되지 않으므로 별도 입력
• 확정급여제도 재측정: 보험수리적손익 — 음수/양수 모두 가능
• FVOCI 평가: 미실현평가손익 — 처분 시 당기손익 재분류
• 리스비용: IFRS 16 적용으로 사용권자산상각비 + 이자비용으로 분리
• 총포괄이익 = 당기순이익 + 기타포괄손익 — 최종 확인

📚 K-IFRS vs K-GAAP 주요 차이점
구 분K-IFRSK-GAAP
적용대상상장법인·금융기관 의무비상장 비외감법인, 중소기업
손익구조당기순이익 + 기타포괄손익 = 총포괄이익당기순이익만 표시
리스(Lease)IFRS 16: 사용권자산/리스부채로 재무제표 인식운용리스는 비용 처리
금융자산FVTPL / FVOCI / 상각원가 (3범주)단기/장기 투자자산 (만기·목적 기준)
재고자산후입선출법(LIFO) 금지후입선출법 허용
투자부동산공정가치 모형 또는 원가모형원가모형만 허용
주재무제표연결재무제표가 주재무제표별도재무제표가 주재무제표

변환 흐름: 은행 여신심사 시스템에 입력한 계정명을 NICE·KED 외부신용평가 체계의 계정명으로 매핑·제출합니다. 은행 시스템의 세부 항목이 외부평가사에서 묶여 집계될 수 있으므로, 어떤 항목이 어디로 합산되는지 확인하는 것이 핵심입니다.
